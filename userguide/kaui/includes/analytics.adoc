=== Overview

The Analytics page is only available when the https://github.com/killbill/killbill-analytics-plugin[analytics plugin] is installed. Refer to the https://docs.killbill.io/latest/userguide_analytics[Analytics Plugin Manual] for further details about the plugin.

The analytics page allows you to view reports. It also has filtering capabilities. We provide a few by default. These can be installed as explained in the https://docs.killbill.io/latest/userguide_analytics#installing_canned_reports[analytics manual]. In addition, the analytics plugin lets you https://docs.killbill.io/latest/userguide_analytics#create_custom_reports[create custom reports].

=== Report Configuration

The Analytics UI can be used to view/create/edit/delete a report. These report operations can also be performed by invoking the report APIs documented https://docs.killbill.io/latest/userguide_analytics#_report_apis[here].

In order to perform these operations via Kaui, click the "Configure Reports" button in the Analytics UI:

image::../assets/img/kaui/analytics/configure-reports-button.png[width=850,align="center"]

==== View Reports List

Click on the "Configure Reports" button in the Analytics UI. This displays all the existing reports:

image::../assets/img/kaui/analytics/reports-list.png[width=850,align="center"]

==== Create Report

1. To create a report, click on the "New Report" button in the "configured reports" screen:
+
image::../assets/img/kaui/analytics/new-report.png[width=850,align="center"]
+
2. This displays the "Add New Report" UI. Enter appropriate details and click the "Save" button:
+
image::../assets/img/kaui/analytics/create-new-report.png[width=850,align="center"]


==== Edit Report

1. To edit a report, click on the "Edit" button next to the report:
+
image::../assets/img/kaui/analytics/edit-report.png[width=850,align="center"]
+
2. This displays the "Update Report" screen. Make the desired changes and click the "Save" button:
+
image::../assets/img/kaui/analytics/update-report.png[width=850,align="center"]

==== Delete Report

To delete a report, click on the "Delete" button next to the report:

image::../assets/img/kaui/analytics/delete-report.png[width=850,align="center"]

==== Refresh Report

To refresh a report, click on the "Refresh" button next to the report:

image::../assets/img/kaui/analytics/refresh-report.png[width=850,align="center"]

For more information, see the https://docs.killbill.io/latest/userguide_analytics.html[_Analytics Guide_].
