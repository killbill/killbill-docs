== March 24th 2026

* *Getting Started Screen* - Aviate now supports one click AWS setup and provides ready instructions for Docker setup.
* *Email Templates* - Users can now configure Email Templates for different scenarios like Invoice Creation etc. 
* *Plugin MarketPlace Screen* - All the Install, Uninstall and Update plugin operations are supported.
* *Billing Meter* - Added support for additional aggregations like MAX, COUNT, LATEST, UNIQUE_COUNT.


== March 10th 2026

* *Aviate Plugin Release* - Version *1.0.41* of the aviate plugin has been released. It includes new metrics to track server side prepared statements.

== March, 3rd 2026

* *Plugin MarketPlace Bug Fixes* - Several bug fixes have been implemented in the plugin marketplace, enhancing the overall user experience. These fixes address issues related to oss plugin installation ensuring a smoother and more reliable process for users when interacting with plugins.
* *Aviate Catalog Bug Fixes* - A number of bug fixes have been applied to the Aviate Catalog, improving its stability and performance.
** *Usage Price Currency Selection* - Fixed an issue where the top currency would duplicate when selecting multiple currencies for a usage price.
** *Advanced Options Visibility* - Fixed an issue where advanced options were incorrectly displayed in the per-plan UI.

== February, 24th 2026

* **Plugin Configuration Screen**
There have been several bug fixes in the plugin configuration screen,delivering a smoother and more seamless experience for users. These fixes eliminate previous glitches. As a result, configuring plugins is now faster, more reliable, and less error-prone.

== February, 10th 2026

* **Create Tenant Option**
The Add Tenant form now includes a “Create if missing” option, allowing users to automatically create a tenant in the selected deployment if it does not already exist. This streamlines setup and removes the need for manual pre-creation.

* **Delete Plan/Product Feature**
Additional features have been introduced in the Aviate Catalog that allow deleting plans/products that have been created erroneously.


== February, 3rd 2026

* **Additional Aviate Catalog Features**
Additional features have been introduced in the Aviate Catalog to make plan management more efficient and flexible. The new *Duplicate Plan* option allows users to quickly create a new plan based on an existing one, significantly reducing the time required during setup. Meanwhile, the *Archive Plan* feature makes it possible to retire plans gracefully by preventing new subscriptions from being created, while still preserving historical data. Together, these enhancements streamline workflows and give users greater control over how they manage their catalog of plans.


* **Kaui Integration**
Aviate now offers seamless integration with Kaui, the Kill Bill administrative console. Users can easily access Kaui directly from the *Billing Operations* section. This enhancement streamlines workflows by providing quick navigation to  billing and account management features, making it easier to perform tasks such as account creation subscription management, invoice reviews — all from within Aviate.

== January, 27th 2026

* **Plugin marketplace**
The plugin marketplace is now exposed in Aviate, making it easier to discover, browse, and enable available plugins directly from the UI. This lays the groundwork for a richer ecosystem of extensions and integrations, and gives administrators better visibility into what functionality can be added to their billing stack without custom development.

* **Invoice Template Feature**
With the invoice template screen, users can now edit company information (name, address, city, country, and URL) directly within the Kill Bill Aviate platform, with options for both simple and advanced editing modes.

== January, 20th 2026

* **Dedicated API key management page**
A new dedicated page allows administrators to manage API keys at the tenant level. From this screen, users can create, rotate, and revoke API keys, making it simpler to control access, improve security hygiene, and support operational workflows without relying on manual configuration.

* **Aviate Tax configuration screen**
A new Tax configuration screen has been added to Aviate, providing a centralized place to view and manage tax-related settings. This improves clarity around tax behavior and reduces the need to switch between tools or rely on low-level configuration.

* **Direct links to Kaui**
Relevant areas of Aviate now include direct links to Kaui, making it easier to move between configuration in Aviate and detailed operational views in Kaui. This helps streamline day-to-day workflows for teams that use both tools side by side.

* **UX improvements and bug fixes**
Various bug fixes and user experience improvements were rolled out across the UI. These changes focus on smoother navigation, clearer feedback, and small quality-of-life enhancements based on early user feedback.
